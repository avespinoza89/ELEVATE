# ELEVATE Commons - Category Structure

This document defines the category structure for the ELEVATE Commons Discourse platform.

## Category Hierarchy

**Slug**: `general`

## Category Management

### Moderation Guidelines

1. **All Categories**:
   - Respectful dialogue required
   - No spam or self-promotion
   - On-topic discussions
   - Follow community guidelines

2. **Resource Library**:
   - Quality control for uploads
   - Verify resource authenticity
   - Check for duplicates
   - Ensure proper attribution

3. **Collaboration Opportunities**:
   - Verify member organizations
   - Monitor for authenticity
   - Facilitate connections

4. **Events & Webinars**:
   - Verify event details
   - Update event status
   - Archive past events

### Category Review Schedule

- **Monthly**: Review category usage and engagement
- **Quarterly**: Assess need for new categories or consolidation
- **Annually**: Major category structure review

### Adding New Categories

When proposing new categories, consider:

1. **Is there sufficient demand?** (10+ potential topics)
2. **Is it distinct from existing categories?**
3. **Will it fragment the community?**
4. **Does it align with ELEVATE's mission?**

## Implementation Notes

### Initial Setup

1. Create categories in the order listed
2. Set appropriate colors and icons
3. Configure permissions for each category
4. Add welcome topics to each category
5. Enable subcategories where specified
6. Set up tagging system
7. Configure moderation settings

### Post-Launch

1. Monitor category usage
2. Adjust permissions as needed
3. Add/modify subcategories based on community needs
4. Update category descriptions
5. Feature popular topics
6. Archive inactive categories
